# 错误复盘：从 Valaxy 主题覆写到自主建站

## 时间线

| 阶段 | 做了什么 | 问题 |
|------|---------|------|
| 1 | 尝试用 CSS 覆写 valaxy-theme-yun | 完全失败——CSS 选择器对不上真实 DOM |
| 2 | 导出设计稿 HTML，获取精确规范 | 有了准确数据，但仍在 Valaxy 框架内挣扎 |
| 3 | 用户要求"不要拘泥于框架" | **关键转折**——放弃 Valaxy，从零搭建 |
| 4 | Vite + Vue 3 自主建站（第一版） | 能 build 但和设计稿差距巨大 |
| 5 | 仔细研读导出 HTML，逐像素对照（第二版） | 基本成型，但仍有多处偏差 |
| 6 | 多轮迭代修复 | 逐步完善 |

---

## 核心错误

### 错误 1：试图在陌生框架上"覆写"而不是"重建"

**错误做法**：对着 valaxy-theme-yun 的几十个组件、几百行默认样式写 CSS 覆写。

**为什么错**：
- 主题的实际 DOM 结构（class 名、嵌套关系）和我想象的完全不同
- 层级替换无法做到像素级还原
- 一条 `!important` 覆盖另一条 `!important`，越改越乱

**正确做法**：从头建站，CSS Grid 三行搞定整站布局，每个组件自己写 HTML。

---

### 错误 2：颜文字用 HTML 实体编码（`&#x...`）而非直接写字符

**错误做法**：
```html
&#x0E6E;&#x0E3E;...  <!-- 十六进制码写错了，变成了完全不同的字符 -->
```

**为什么错**：
- 手动算 Unicode 码点极易出错
- 写错了编译器不报错，只是显示为乱码
- 全文搜索替换都极其麻烦

**正确做法**：
```html
૮₍˶ᵔᵕᵔ˶₎ა  <!-- 直接复制粘贴，所见即所得 -->
```

---

### 错误 3：CSS 变量放在 App 子节点上，body 拿不到

**错误做法**：
```css
.app.dark { --c-bg: #1a1a1a; }
body { background: var(--c-bg); }
```

**DOM 结构**：`<html> > <body> > <div#app> > <div.app>`

**问题**：`.app` 是 `body` 的子节点，CSS 变量无法向上继承。

**正确做法**：
```css
html.dark { --c-bg: #1a1a1a; }
```
并同步给 `<html>` 元素加 class。

---

### 错误 4：硬编码 `color:#2d2d2d` 在暗色模式看不清

**问题**：标签、徽章等元素写死了 `color:#2d2d2d`（深灰）。亮色模式没问题，暗色模式下粉/绿背景变暗，深色文字对比度不足。

**正确做法**：暗色模式下提亮强调色（`#9575cd` → `#c9b1e8`），确保深色文字在彩色背景上仍有 7:1 以上对比度。

---

### 错误 5：大纲栏 `position:sticky` 在滚动容器内无效

**错误做法**：
```css
.outline-sidebar { position: sticky; top: 48px; }
```
但大纲栏父级 `.content-area` 本身就是滚动的，`sticky` 相对父容器定位，用户滚动时跟着跑。

**正确做法**：
```css
.outline-sidebar { position: fixed; right: 0; top: 48px; }
```
脱离文档流，始终固定在视口右侧。父容器加 `padding-right` 预留空间防止重叠。

---

### 错误 6：分页算法用 `clientHeight` 获取 0

**错误做法**：`onMounted` 时读取 `contentRef.value.clientHeight`，值为 0（DOM 未渲染完成）。

**迭代过程**：
1. `clientHeight` → 0 → 分页失效
2. `window.innerHeight` 减固定偏移 → 总是溢出滚动条
3. 最终方案：`window.innerHeight - 200` / 80，保留两个可调参数

**教训**：静态尺寸计算优先用 `window.innerHeight`，别依赖异步渲染后的 DOM 尺寸。

## 本应一开始就做的事

1. **导出设计稿为 HTML**，直接拿到 Tailwind class 里的精确 px 值、颜色、间距
2. **从头建站**，不要在任何已有框架上覆写
3. **逐组件对照**——顶栏、侧栏、文章卡片、大纲、底栏——挨个匹配
4. **暗色模式用 `html.dark`** 而非子节点 class

---

## 最终成果

- 独立 Vite + Vue 3 项目，无外部博客框架依赖
- 7 个页面，严格按设计稿 px 值还原
- 暗色/亮色一键切换，CSS 变量从 `html` 根节点生效
- 文章用 Obsidian 兼容的独立 `.md` 文件
- 侧栏选项卡、搜索、分页、响应式适配全功能
